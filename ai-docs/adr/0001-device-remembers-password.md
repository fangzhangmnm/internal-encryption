# ADR-0001 设备可以记住口令（opt-in、不可导出钥匙封装、≤ 30 天过期）
> created 20261017 · by Claude Fable 5.1 · status: accepted（user 2026-10-15 / 2026-10-17 拍板）· as-of @internal/encryption 0.2.0
> 对 store 仓 ADR-0012「Password is memory-only, never persisted」那一行的**有意吃书**。ADR-0026（口令来源 = 生成短语 + 平台凭据管理器）方向不变、仍未实现，与本 ADR 互补不冲突。

## 决定

1. 家族 app 可以让**这台设备**记住内容口令，进来不用再输。能力住 `@internal/encryption`（`createPasswordKeeper`），三个要口令的 app（KudsRocket / WebXiaoHeiWu / WeebPaint）共用一份，不各写各的。
2. **按设备 opt-in**：口令面板一个勾「在这台设备上记住」，默认不勾。记了就一直有「忘记」。
3. **存的是口令本身**，不是派生钥匙（容器每个文件一个 salt，派生钥匙不通用）。盘上**没有明文**：口令用同一个 IDB 库里一把**不可导出**的 AES-GCM 钥匙封起来再存。
4. **过期时间，上限 30 天**（user 2026-10-17「口令加一个过期时间，最多一个月」）。缺省就是上限；app 可以给更短；超过上限一律钳到上限——上限是库里的常数，不是可配置项。过期时间进 AES-GCM 的 additionalData，在库里改它就解不开。
5. 记着的口令只是「第一把试的钥匙」：app 照旧先验（verifier 记录 / 容器 peek），对不上就 `forget()` 再弹框。它是四等公民（设备状态），**永不驱动破坏性操作**。
6. 「立即锁定」/ 退出登录 = `forget()`；清本机缓存 / 强制更新**不**清它（它不是缓存）；还原出厂清它；换口令 = `remember()` 新的。

- 为什么不「跟着 store」：store 的红线是「store 不存口令、口令经 seam 非交互拿」（ADR-0012），这条不动；记住口令是口令面板那一侧的事，所以住加密库，不住 store。

## 威胁模型（对齐家族 `ai-docs/20261016-data-safety-model.md`）

- **加密防的是云端那一方**（微软读 blob、网盘泄露、误分享、内容审查——§3 B4）。拿着已解锁设备的人本来就什么都看得见：OneDrive app、浏览器都登着。ADR-0026 原则一「把密钥交给已经能看见明文的一方是免费的」顺下来：**记住口令不新增信任方，新增的只是「时间」**——会话结束后口令还留在设备上。过期时间就是给这段时间封顶。
- 多出来的暴露面与对策：
  1. 设备在解锁状态下被拿走 = 全开（§3 D1）。和 OneDrive app 一样，接受；user 知情 opt-in；30 天后自动作废。
  2. 同源脚本能读到口令（XSS）。家族无 CDN、无第三方脚本、依赖全 vendor；残余 = 渲染用户内容的 innerHTML。~~家族目前没有一个 app 有 CSP~~——这是接本功能的 app 该补的一层，不是本库能替它做的。（2026-10-17 三家都上了 meta CSP：WeebPaint v0.14.34 / WXHW v2.3.41 / KudsRocket v0.1.58；家族根 memory「家族页面 CSP」有现状。edited by Claude Fable 5.1 2026-10-21）
  3. 浏览器数据进系统备份 / 被整 profile 拷走。不可导出钥匙在多数平台上随 profile 一起走，**按能解来算**（未逐平台核实，不当承诺）。
  4. 丢设备后换口令 = 旧密文 + 旧口令在对方手里照样开。这是端到端加密的底价，记不记口令都一样（ADR-0026「被否决的替代方案」里已说清）。
  5. 时钟往回拨能延命。接受（拿着设备的人本来就能开）；反方向做了保守处理：expiresAt 比「现在 + 上限 + 1 天」还远 = 时钟被拨过 / 记录不对 → 当没记。
- 本模块永不打印口令，抛出的错误里没有口令；`recall()` / `status()` 永不抛（四等数据丢了就重问）；`remember()` / `forget()` 的存储错误原样抛（调用方要知道没记上 / 没忘掉）。

## 取舍（明说）

- **存口令本身 vs 存派生钥匙**：三个 app 的容器都是每文件一个 salt 的 PBKDF2 / 7z AES，派生钥匙不通用，只能存口令。要存派生钥匙先得做密钥分层（ADR-0026 里说的「正确卖点」，格式级变动，以后）。
- **固定过期 vs 滑动过期**：固定（记那一刻起算）。滑动对天天用的人等于永不过期，违背「最多一个月」的意思。过期后重输一次、再勾一次。
- **钳住 vs 抛错**：app 传了超上限的 ttl 钳到上限而不是抛——结果仍在政策内，面板按返回的 `expiresAt` 显示真实日期即可。
- **库名归 app**：`<app>.remember`（家族前缀规矩「`<app>-…` = 那个 app 私有」）。KudsRocket 现用 `kudsrocket.remember`，搬库时不改名（改名 = 已记住的人重输一次，不值）。

## 否决（勿再 re-litigate）

- **localStorage**：只能存字符串 = 明文落盘。
- **放进 store / 跟着同步**：口令离开设备 = 新增信任方（ADR-0012 / 0026 原则一）。
- **只靠浏览器密码管理器自动填**（ADR-0026 落地清单第 1 条）：user 2026-10-15「要的不是密码管理器自动填（那还要 Face ID 一下），是这台设备记住、进来不用输」。ADR-0026 作为口令**来源**仍成立，和本 ADR 不冲突。
- **app 自己做图案 / 手势锁**：等于 app 存口令 + 自造一道弱锁，不如直接记住 + 过期。
- **可配置的更长上限**：30 天是 user 定的红线，改要先问人。

## 给消费方的落地清单（每个接的 app 都要过一遍）

1. 口令面板：一个勾「在这台设备上记住」，默认不勾；勾旁一句实话「能解锁这台设备的人就能打开你的东西」；记住后面板 / 设置里显示「记到 X 月 X 日」+「忘记」。
2. 启动：`recall()` 拿到口令 → **先验**（verifier / peek）→ 对就当已解锁；不对 → `forget()` + 照常弹框（并说一句「这台设备记着的口令打不开，别处换过口令？」）。
3. 「立即锁定」/ 退出登录 → `forget()`。闲置锁屏（WXHW 2 分钟那种）本来不忘口令，不变。
4. 换口令 → 记着的话 `remember()` 新口令（沿用原来的 ttl 或重问）。
5. 还原出厂 → `forget()`（或整库 deleteDatabase）；清本机缓存 / 强制更新**不**碰它。
6. 持久层白名单：接缝文件登记进该 app 的白名单表 + 守卫测试；值级 import 只准接缝文件（各 app 的 build lint 已有同款规则）。
7. 该 app 的 ADR 补一条短的指到这里（KudsRocket 已在 CLAUDE.md 记过，可补 ADR）。
8. **和别人共 origin 的分发形态不提供**（2026-10-17 WeebPaint 查出、user「做」；edited by Claude Opus 5.5）：file:// 单文件 html（Chromium 所有本地 html 共一个存储桶）、itch（所有网页游戏共 `html-classic.itch.zone`）这类形态里，同源的别人能拿那把钥匙直接解——整个关掉（不给勾、不恢复、不碰存储）。WeebPaint = `isStandaloneHtml()`。
9. 真机：iPad Edge（user 的日常）至少验一次「记住 → 关页 → 重开不用输 → 忘记 → 要输」。
10. **prod 和 `/dev/` 同源 = 同一把记住的钥匙，接受、不按频道分库名**（周账 F-62，2026-10-21 Claude Fable 5.1 审后判定，**等 user 点头**）。三家的库名都不带频道（`weebpaint-….remember` / WXHW `REMEMBER_DB` / `kudsrocket.remember`），站点根 = prod、`/dev/` = dev 是同一个 origin，所以共用。为什么不分：同源已经共用得更多——store 的本机库（`<appId>.defaultStore`，dev 本来就在真数据上测）、MSAL 的令牌缓存（dev 页能用 prod 的登录拉云端密文）；dev 里的 XSS 拿得到的远不止这把钥匙，分开只是看起来安全。而且 user 在 dev 里也会勾「记住」，分开 = 两条记录、同一个口令，攻击面一样。真正挡 XSS 的那层是 CSP（第 2 条），10-17 已上。会发生的唯一交互：dev 先收了带新 `RECORD_VERSION` 的库版本 → prod 读到认不得 → 顺手删 → prod 下次要重输一次（保守方向，不丢东西）。
